# 비기몽 캐릭터 도감 제작 기준 v0.7

## 공통 규칙

- 총 30종이며 등급은 없다. 부화 확률은 모든 종이 동일하다.
- 성장 단계는 `GROWTH`(성장기/아동기), `YOUTH`(청년기), `ADULT`(성인기)다.
- 앱 자산은 `bigimong_번호_단계.webp` 형식이며 총 90개다.
- 기존 3D 참고판과 번호가 겹치는 캐릭터는 기존 색·실루엣·핵심 특징을 우선 유지했다.
- 의상과 액세서리는 상점 코스튬 레이어로 분리하기 위해 기본 캐릭터 원화에는 고정하지 않았다.
- 눈·날개 랜덤 색상은 후속 마스크 자산으로 분리하며 현재 원화는 종의 대표색이다.
- 사용자 참고표에 25번이 없으므로 25번은 임시 테리지노사우루스다. 25번 원화가 제공되면 동일 `artId`의 3개 파일만 교체한다.

## 앱 표시 규칙

| 서버 성장 단계 | 표시 단계 | 자산 접미사 |
|---|---|---|
| GROWTH | 성장기/아동기 | `growth` |
| YOUTH | 청년기 | `youth` |
| ADULT | 성인기 | `adult` |

기존 사용자에게 저장된 옛 종 키는 서버에서 가장 가까운 새 도감 종으로 변환한다. 도감 번호와 성장 단계는 부화 공개 화면, 홈 화면, 대전 참가자 카드에 동일하게 적용한다.
