# 비기몽 v0.13 — 참고 디자인 반영과 AR 카메라 구성

이번 변경은 사용자가 제공한 세 이미지의 방향을 실제 런타임 모델과 UI에 적용한다. 원본 PNG는 공개 저장소에 포함하지 않는다. 캐릭터 번호·속성·전투 규칙은 기존 도감을 기준으로 유지한다.

## 시각 변경

- 아바타: 큰 눈과 하이라이트, 부드러운 얼굴과 머리 형태, 어두운 기본 의상, 스튜디오 형태의 커스터마이징 화면.
- 몬스터: 종별 색과 실루엣, 크림색 배·주둥이, 눈 하이라이트와 분리 가능한 액세서리. 30종의 기존 ID와 3단계 성장 크기를 유지한다.
- 전투: 청록색 바닥 링, 남색 반투명 패널, 상태에 반응하는 HP 표시와 방향 버튼.

런타임에서 생성하는 3D 형상을 개선하는 단계이며, 참고 이미지 수준의 전문 제작·리깅·텍스처 자산 완성을 뜻하지 않는다. 실제 AR 배경 대신 참고 사진을 띄우지 않는다.

## AR 구성과 검증

기존 APK에는 ARCore 실행 로더가 지정되지 않아 카메라 권한과 ARCore 네이티브 라이브러리가 포함되지 않았다. 빌드 과정에서 Android XR 설정과 ARCore 로더를 저장하고, ARCore를 선택 기능으로 구성해 화면 고정 대체 모드를 유지한다. XR 입력의 유효한 카메라 위치·회전만 적용하며 추적이 끊기면 마지막 위치를 유지한다.

Unity 빌드 전에 실행하는 Editor 검사는 XR 설정의 반복 실행 안정성, 로더, 카메라 연결과 유효/무효 추적 입력을 확인한다. 생성된 APK는 다음을 검사해야 업로드된다.

- `com.bigimong.app`, 버전 `0.13.0`, 코드 `13`, 최소 Android API 28, 대상 API 35 이상
- ARM64 Unity 및 ARCore 네이티브 라이브러리, 다른 ABI 미포함
- CAMERA 권한, 선택형 ARCore 메타데이터
- Android SDK `apksigner verify` 성공과 서명 인증서 정보

출력은 `Bigimong-AR-v0.13-debug.apk`, 검증 JSON, SHA-256 파일이다. Node 검사 성공만으로 Unity 컴파일이나 실제 기기 AR 동작을 보증하지 않는다. Unity CI 결과와 실제 산출물을 확인한 뒤 APK를 제공한다.

## 설치와 남은 기기 확인

개발용 APK는 빌드마다 서명 인증서가 달라질 수 있다. 이미 설치한 v0.12와 서명이 다르면 Android가 덮어쓰기를 허용하지 않는다. 기존 앱을 삭제하면 로컬 진행 정보도 지워질 수 있으므로 자동 삭제나 데이터 초기화를 수행하지 않는다. 새 APK의 검증 보고서에 인증서 정보를 남긴다.

실제 휴대폰에서 카메라 권한 요청, 바닥 인식, 이동 중 위치 추적, 추적 상실/복귀, 화면 고정 모드와 아바타·전투 화면의 시각 품질을 추가 확인해야 한다.
