# Bigimong v0.16 — Image-faithful AR summon design

## Status and authority

The user approved this direction on 2026-09-14: preserve the five supplied portrait UI images, make dinosaurs and avatars match the supplied character references, use a Tripo-to-Blender pipeline, add a thrown summoning medallion and magic-circle reveal, animate every button, add subtle home motion, remove the baked cursor from avatar selection, and make surrender return directly to Home. The already-authorized publication target remains the public `suminjeong-60/bigimong` repository on `feature/v0.12-offline-beta`.

## Product truth

v0.16 must never describe procedural stand-ins as reference-identical models. The current procedural geometry remains a fallback until a generated model passes the visual acceptance gate in `docs/art-reference/EXACT_CHARACTER_ACCEPTANCE.md`. A single-view Tripo output has provisional unseen surfaces; final approval needs front, left, back, and right reference renders.

| Loading | `ReferenceUi/loading` | progress pulse and ambient light only |

| Home | `ReferenceUi/home` | dinosaur/avatar breathing-scale illusion, floating motes, all named navigation destinations |

The familiar AR interaction is implemented with Unity AR Foundation/ARCore—plane detection, reticle, tap-to-place, anchor, scale and lighting adaptation, and a screen-fixed fallback. No proprietary Pokémon GO code, art, audio, names, or trade dress is copied.

## Tripo generation gate

1. Prepare transparent, tightly cropped, high-resolution reference views for each model.
2. Prefer `tripo3d/h3.1/multiview-to-3d` with images ordered `[front, left, back, right]`. With one view, use `tripo3d/h3.1/image-to-3d` and mark the result provisional.
3. Pilot only the two avatars and three Tyrannosaurus stages. Do not batch all 92 character meshes before approval.
4. Record endpoint, model version, seeds, source SHA-256, PBR/quad flags, face limit and returned job ID in a manifest.
5. The user's free-first preference is binding: preparing and validating the pipeline is free; any billable Tripo/Fal generation remains a separate explicit execution gate.

Recommended pilot options are `geometry_quality=detailed`, `texture_quality=detailed`, `texture_alignment=original_image`, `pbr=true`, `quad=true`, `orientation=align_image`, `auto_size=false`, and a 30,000-face source ceiling before mobile reduction. These are versioned inputs, not a promise of visual identity.

## Blender and Unity contract

- Accept `.glb`, `.gltf`, `.fbx`, or `.obj`; preserve PBR textures.
- Join only body pieces that must deform together. Keep eyes, teeth, tongue and cosmetics named and separate.
- Apply rotation/scale, put the lowest evaluated world-space vertex at `Z=0`, then set the object origin at `(bounds center X, bounds center Y, lowest Z)`.
- Use meters, forward direction `-Y` in Blender and Unity-facing conversion on export; verify feet contact the ground without hidden offsets.
- Target roughly 20–35k triangles for a hero adult, 12–25k for baby/teen and avatars, and 1–2 shared 2K texture atlases per character.
- Required clips: `Idle`, `SummonRise`, `Attack_LEFT`, `Attack_CENTER`, `Attack_RIGHT`, `Dodge_LEFT`, `Dodge_CENTER`, `Dodge_RIGHT`, `Hit`, `KO`, and `Victory`.
- Export validated GLB for review and FBX for Unity animation. Create a report containing dimensions, triangle count, materials, texture paths, bottom-origin error and missing clip names.

## Motion and state rules

Every interactive Unity `Button` gets unscaled-time press motion: 1.00 → 0.92 in 0.06 s, rebound to 1.04 in 0.08 s, settle to 1.00 in 0.08 s. Cancellation/disable always restores scale. Home uses subtle, non-drifting 2D motion with no hotspot misalignment. Summoning orders anticipation → medallion throw → ground impact → traced circle → shockwave/light column → dinosaur rise → avatar step-back → battle unlock. Tracking loss cancels the active generation and resets every temporary object.

A surrender action is visible during offline AR battle. It stops the demo, ends battle playback, cancels summon/VFX, disables placement, requests re-anchor cleanup, returns the flow to `PetTestSelect`, and signals the reference UI to show Home. It grants no reward and cannot be mistaken for a defeat.
