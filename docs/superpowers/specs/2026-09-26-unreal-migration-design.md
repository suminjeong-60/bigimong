# 비기몽 Unreal 전환 설계 (2026-09-26)

## 목표와 기준

비기드래곤/비기몽 Android 게임의 화면·캐릭터·AR 런타임을 Unreal Engine으로 옮긴다. 서버가 이미 담당하는 계정, 검증된 걸음, 부화 소유권, 매칭, 대전 판정, 정산의 권한은 유지한다. 기존 Unity 코드는 마이그레이션 검증과 롤백의 기준으로 남긴다. 새로운 VARCO 남성 모델을 생성하지 않고 APK에 포함된 남녀 원본을 사용한다.

## 확인한 현재 상태

- GitHub `feature/v0.19-3d-hatch-home`이 현재 개발 기준이다. Android Kotlin/Compose는 Health Connect, BLE, 서버, 대전 화면을 담당하고 Unity는 AR 화면과 독립 부화·홈 후보를 담당한다.
- `01-BigiDragon-0.3.1-Compatible.apk`에는 남녀 VARCO GLB와 커스터마이징 부품이 있다. 모델에 동봉된 출처 기록의 SHA-256을 실제 파일과 비교했다.
- 남성 원본: 500,000삼각형, 재질 1개, 스킨/애니메이션/모프 0개. 여성 원본: 25,000삼각형, 재질 1개, 스킨/애니메이션/모프 0개. 두 모델의 기존 표시용 외형과 게임용 리깅은 별도 작업이다.
- 기존 여성 아바타 명세는 얼굴/눈/헤어 15종씩을 요구하며 이 선택 UI·모델 결합은 아직 완료로 확인되지 않았다. 베이스 조각의 모프 수만으로 3,375개 최종 외형을 승인하지 않는다.

## 접근과 단계

1. **엔진 기반 및 원본 확인**: 별도 `unreal/Bigimong` C++ 프로젝트와 Android 개발용 패키지를 만든다. 공개 저장소에는 모델 바이너리와 인증 정보를 넣지 않는다. 사용자 APK에서 고정 해시로 남녀 원본을 추출하고, 삼각형·리그 상태를 검사한다. 에디터에서 원본을 정적 메시로 불러오는 재현 가능한 절차를 만든다. 홈 아바타 미리보기의 카메라와 터치 회전 코드를 작은 수직 기능 단위로 둔다.
2. **홈·부화·프로필 이식**: Unity v0.19 상태 스키마 v2의 단계, 30,000점, 알 돌봄 2시간, 선택 결과의 재시작 복구를 Unreal 저장/서버 연결에 옮긴다. Health Connect의 걸음은 Android 네이티브 연결 및 기존 서버를 통해서만 반영한다. 디버그 버튼으로 운영 걸음수를 만들어 내지 않는다. 같은 프로필이 홈·전투·소환에 사용되도록 한다.
3. **AR 전투 이식**: Epic의 Handheld AR 기반 Android 바닥 인식·배치·추적 유실 처리를 구현한다. 기존 서버의 `battleId`, HP, 10초 제한, 좌/중/우 선택, 모션 키, 자동 플레이, 재연결 스냅샷을 유지한다. BLE/Health Connect 통합을 Android 네이티브 모듈로 이전하고 두 대 기기에서 검증한다.
4. **자산·출시 검증**: 남성 모델의 모바일 리토폴로지, 남녀 리깅, 여성 15×15×15 커스터마이징, 목걸이 소환과 30종×3단계 공룡 아트를 제작·검수한다. Galaxy Ultra 실기기에서 화면·카메라·성능·설치·서버전투를 검사한 다음 기존 `com.bigimong.app` 배포 ID와 데이터 마이그레이션을 결정한다.

## 이번 수직 기능 단위의 경계

첫 전달물은 Unreal C++ 프로젝트, APK 원본 검증·추출 도구, 기본 홈 뷰어와 자산 가져오기 안내다. 독립 Android 미리보기 ID를 사용해 기존 설치 앱과 충돌하지 않게 한다. 이 실행 환경에는 Unreal Editor와 Android 빌드 도구가 없어 여기서 Unreal 컴파일, GLB 실제 에디터 가져오기, AR 실행, APK 생성을 확인할 수 없다. 그 단계들은 완료 표시하지 않는다.

## 검증과 오류 처리

- GLB magic/길이/접근자에서 삼각형·스킨/모프를 검사하며 남녀 SHA-256 불일치, 누락된 경로, 잘못된 ZIP, 기존 다른 내용 파일 덮어쓰기는 실패시킨다.
- 모델 원본은 고정 해시를 만족할 때만 추출한다. 공개 Git에는 저장하지 않는다. 에디터에서 Static Mesh로 표시 후 실측 Bounds, 기준 사진의 얼굴·재질·조명 일치도를 확인한다.
- 남성 원본은 기존 30,000삼각형 모바일 예산을 초과하므로 실기기 배포 자산으로 선언하지 않는다. 커스터마이징 조각 역시 별도 측정·육안 검수 전에는 완성으로 선언하지 않는다.
- 서버 판정과 Android 데이터를 한 번에 새 클라이언트로 복사하지 않는다. 서버 계약/앱 저장 데이터의 실제 호환 테스트가 끝나야 기존 앱을 교체한다.
