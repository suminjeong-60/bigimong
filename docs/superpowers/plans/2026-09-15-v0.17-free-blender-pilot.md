# Bigimong v0.17 Free Blender Character Pilot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce, visually review, integrate, and ship five reference-led Bigimong character models without calling any paid generation API.

**Architecture:** A manifest-driven Blender Python pipeline generates continuous stylized meshes, embedded texture atlases, armatures, actions, mobile FBX/GLB exports, and fixed-camera contact sheets on GitHub Actions. After the user approves the rendered pilot, a Unity editor importer turns the accepted FBX files into stable Resources prefabs and animator controllers before the existing ARM64 APK build runs.

**Tech Stack:** Node.js 24 built-in test runner, Python 3, Blender Python (`bpy`, `bmesh`, `mathutils`), GitHub Actions, Unity 6000.0.58f2, C#, AR Foundation 6.1.1, Android ARM64.

**Spec:** `docs/superpowers/specs/2026-09-15-v0.17-free-blender-pilot-design.md`

## Global Constraints

- Do not call Tripo, Fal, or any other billable 3D or image generation endpoint.
- Do not require DigitalOcean or another paid server.
- Generate the five-model pilot first; do not begin the 90-model expansion in this plan.
- Treat the supplied reference images as visual authority and label unseen rear surfaces as inferred.
- A primitive-only sphere/capsule assembly is not an accepted model.
- Target 18,000–25,000 rendered triangles and enforce a hard maximum of 30,000 per character.
- Use one embedded 1024×1024 RGBA atlas per character and no more than four material slots.
- Use no more than 64 deform bones and 16 non-deforming attachment/control bones.
- Export roots at ground contact with `Z=0` and a bottom-origin error no greater than 1 mm.
- Required actions are `Idle`, `Summon`, `Attack`, `DodgeLeft`, `DodgeRight`, `Hit`, `Knockout`, and `Victory`.
- Existing button animation, surrender-to-home cleanup, AR placement, and code-generated elemental VFX remain unchanged.
- The five-model visual gate requires front, left, rear, right, and three-quarter renders plus an actual Unity capture.
- Code tests and APK compilation do not constitute visual acceptance.
- Work on `feature/v0.12-offline-beta`; preserve unrelated user changes.

- [ ] **Step 4: Implement the validator**

Export and invoke the same function from the CLI:

```js
export function validateFree3dManifest(manifest, { existsSync, hashObject } = {}) {
  const errors = [];
  if (manifest?.schemaVersion !== 1) errors.push("schemaVersion must be 1");
  if (manifest?.release !== "0.17") errors.push("release must be 0.17");
  if (manifest?.generator !== "blender-python") errors.push("generator must be blender-python");
  if (manifest?.paidApisEnabled !== false) errors.push("paidApisEnabled must be false");
  if (!Array.isArray(manifest?.jobs) || manifest.jobs.length !== 5) errors.push("jobs must contain five entries");
  const ids = (manifest.jobs ?? []).map((job) => job.id);
  const resourceNames = (manifest.jobs ?? []).map((job) => job.resourceName);
  if (new Set(ids).size !== ids.length) errors.push("job ids must be unique");
  if (new Set(resourceNames).size !== resourceNames.length) errors.push("resource names must be unique");
  for (const job of manifest.jobs ?? []) {
    if (!job.sourceAsset || !job.sourceGitBlobSha) errors.push(`${job.id}: source reference is required`);
    if (!Number.isFinite(job.targetHeightM) || job.targetHeightM <= 0) errors.push(`${job.id}: targetHeightM is invalid`);
    if (!Array.isArray(job.requiredParts) || job.requiredParts.length === 0) errors.push(`${job.id}: requiredParts is empty`);
    if (existsSync && !existsSync(job.sourceAsset)) errors.push(`${job.id}: sourceAsset does not exist`);
    if (hashObject && hashObject(job.sourceAsset) !== job.sourceGitBlobSha) errors.push(`${job.id}: source hash mismatch`);
  }
  if (errors.length) throw new Error(errors.join("\n"));
  return { valid: true, ids, resourceNames, paidApisEnabled: false, generator: "blender-python" };
}
```

The CLI must use `git hash-object -- <sourceAsset>` only when a valid Git worktree is available; it always performs schema and path checks.
