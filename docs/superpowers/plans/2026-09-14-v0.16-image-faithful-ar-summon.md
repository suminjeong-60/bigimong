# Bigimong v0.16 image-faithful AR summon implementation plan

**Goal:** ship a verified APK increment that preserves the five approved UI images while adding tactile UI motion, cursor repair, home ambience, a safe surrender-to-home flow, stronger medallion summoning, and a reproducible Tripo/Blender asset pipeline.

**Architecture:** retain `BigimongReferenceUi` as the portrait navigation layer and the existing AR Foundation offline flow. Add one reusable UI press component shared by all generated buttons, one reference-art motion/repair layer, and one explicit flow event for returning Home. Keep Tripo outside runtime: a versioned job manifest describes inputs, and Blender batch processing validates and exports generated assets before Unity import.

**Constraints:** Unity `6000.0.58f2`, AR Foundation/ARCore `6.1.1`, Android IL2CPP ARM64 only, public branch `feature/v0.12-offline-beta`, no secrets in source/logs, no paid Tripo batch without a separate execution gate.

## Task 1: Lock behavior with failing tests

**Files:** modify `tests/ar-project.test.js`, `tests/reference-ui-navigation.test.js`; add `tests/tripo-blender-pipeline.test.js`.

Add observable-contract tests for a visible HUD surrender button wired to `SurrenderToHome`, complete battle cleanup and a Home signal; shared press animation on scene-builder and reference-image buttons; a non-interactive cursor-repair overlay and home ambience; and Blender manifest validation/bottom-origin math. Run `npm test` and confirm only the new tests fail for missing production behavior.

## Task 2: Implement tactile buttons and reference-art life

**Files:** add `unity/BigimongAR/Assets/BigimongAR/Scripts/ButtonPressMotion.cs`; modify `BigimongReferenceUi.cs` and `BigimongArSceneBuilder.cs`.

Implement pointer-down/up/cancel and submit feedback with unscaled time and scale restoration. Attach it to every button factory. Add an avatar-screen mirrored UV repair patch over the baked cursor, marked non-raycast. Add clipped home character overlays with tiny breath/bob motion and no change to hotspot transforms.

## Task 3: Implement surrender-to-home

**Files:** modify `ArBattleHud.cs`, `OfflineBetaFlowController.cs`, `BigimongReferenceUi.cs`, `BigimongArSceneBuilder.cs`, and `OfflineBetaEditorTests.cs`.

Add `surrenderButton`, bind only in offline mode, and route to `OfflineBetaFlowController.SurrenderToHome`. Centralize cleanup so demo, director, summon, arena placement and anchors reset. Raise `HomeRequested`; the reference UI subscribes and immediately calls `ShowHome`. Scene checks verify every serialized reference and label.

## Task 4: Strengthen medallion impact and summon VFX

**Files:** modify `SummonerActor.cs`, `ProceduralMagicCircle.cs`, `SummonSequenceDirector.cs`, and `SummonSequenceEditorTests.cs`.

Separate anticipation and release timing, keep the clone ownership contract, add a code-generated impact shockwave and rune-trace burst, then synchronize light-column reveal and pet rise. Preserve generation cancellation and no-timescale behavior.

## Task 5: Add Tripo/Blender production pipeline

**Files:** add `art/tripo/v0.16-pilot-jobs.json`, `scripts/blender_prepare_bigimong.py`, `scripts/validate-tripo-manifest.mjs`, `docs/TRIPO_BLENDER_v0.16.md`, and `THIRD_PARTY_NOTICES.md`.

Define five pilot jobs and their exact reference/QA briefs. Validate required IDs, endpoints, stage targets and non-empty source hashes. Blender batch imports supported formats, applies transforms, puts the origin on the bottom, normalizes ground contact, lays out review turntables and emits validation JSON. Document free-first and billable execution boundaries plus MIT attribution.

## Task 6: Verify, publish, and build APK

Run `npm test`, run syntax checks for the Blender script outside Blender, inspect the diff, then create a fast-forward GitHub commit on the already-approved public branch. Monitor the `Build Bigimong AR debug APK` workflow, verify artifact metadata and APK SHA-256, and provide the direct GitHub artifact download link. Do not claim reference-identical 3D models until the pilot assets exist and pass the acceptance renders.
