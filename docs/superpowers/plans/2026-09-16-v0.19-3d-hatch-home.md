# Bigimong v0.19 3D Hatch and Focus Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Unity Android beta whose egg, random baby dinosaur, and avatar share one high-quality 3D focus stage with durable 30,000-point hatching, 360-degree touch review, interruption recovery, and reference-matched mobile UI.

**Architecture:** Add a versioned hatch-home domain layer that is independent of Unity presentation, then connect it to one 3D resolver/stage and one responsive view. The coordinator is the only phase owner; persistence, verified-step ingestion, random selection, asset resolution, touch input, animation, and quality scaling communicate through narrow interfaces. Existing AR battle, VARCO import, Android Health Connect, server wallet, and online journey contracts remain intact.

**Tech Stack:** Unity `6000.0.58f2`, C# and uGUI/TextMesh Pro, AR Foundation/ARCore `6.1.1`, Android ARM64/IL2CPP/minSdk 28, Node.js built-in test runner, GitHub Actions, existing VARCO/Resources asset pipeline.

**Spec:** `docs/superpowers/specs/2026-09-16-v0.19-3d-hatch-home-design.md`

## Global Constraints

- Use layout A, **Focus Stage**, with one active 3D subject and approximately 70% of portrait space reserved for it.
- Hatch target is exactly `30000`; one accepted care tap adds exactly `500`; cooldown is exactly two hours.
- Only accepted care and verified step deltas change hatch progress. Gifts, play, quests, purchases, feeding, and navigation do not.
- Reaching 30,000 never auto-hatches; `부화하기` must persist one uniformly selected art ID in `1–30` before animation begins.
- A persisted hatch selection never rerolls after interruption, save recovery, migration, or relaunch.
- First hatch cannot be skipped. Timeline and checkpoints are `STARTED`, `SHELL_BURST`, and `REVEALED`.
- Pre-hatch switch is `비기알 | 아바타`; post-hatch switch is `공룡 | 아바타`.
- Tap threshold is at most `0.22 s` and below `18 dp`; horizontal drag supports unrestricted 360-degree yaw; inertia is at most `0.35 s`; no pinch zoom.
- Base dinosaurs expose no purchasable wearables. Home avatars expose only the neutral base underlayer and no summoning medallion.
- Reuse the existing VARCO `avatar_male`; never issue another generation request for it.
- Imported accepted prefabs win; missing entries resolve to actual 3D procedural fallbacks with the same art ID, body plan, palette, stage, and Korean name.
- Use the supplied `egg.jpg` and `home.jpg` as visual authority. New interactive text uses bundled Noto Sans KR Black/Bold TMP assets with cream/white faces, cocoa outlines, and soft shadows.
- Target 60 fps, maintain at least 30 fps in normal home interaction, keep steady-home memory at or below 350 MB, and hatch peak at or below 450 MB.
- Unity package/application ID remains `com.bigimong.app`; Unity version remains `6000.0.58f2`; AR package versions remain `6.1.1`.
- Keep credentials and provider IDs out of source. Do not push or trigger a remote build without explicit user authorization.

```csharp
[Serializable]
public sealed class HatchHomeSnapshot
{
    public const int CurrentSchemaVersion = 2;
    public const int HatchTarget = 30000;
    public const int ProcessedEventLimit = 256;
    public int schemaVersion = CurrentSchemaVersion;
    public string phase = nameof(HatchHomePhase.EGG_ACTIVE);
    public int eggProgress;
    public long nextCareAtUtcTicks;
    public long lastObservedUtcTicks;
    public int selectedArtId;
    public string hatchCheckpoint = nameof(HatchCheckpoint.NONE);
    public long hatchedAtUtcTicks;
    public string activeHomeView = nameof(HomeSubject.EGG);
    public List<StepProviderCursor> stepProviderCursors = new();
    public List<string> processedStepEvents = new();
    public int dragonExperience;
    public int coins;
    public int snacks;
    public int dayKey;
    public int playsToday;
    public bool giftClaimedToday;
    public bool questClaimedToday;
    public bool soundEnabled = true;
    public long lastPlayTicks;

    public HatchHomePhase Phase =>
        Enum.TryParse(phase, out HatchHomePhase value) ? value : HatchHomePhase.EGG_ACTIVE;
    public HatchCheckpoint Checkpoint =>
        Enum.TryParse(hatchCheckpoint, out HatchCheckpoint value) ? value : HatchCheckpoint.NONE;
    public HomeSubject ActiveSubject =>
        Enum.TryParse(activeHomeView, out HomeSubject value) ? value : HomeSubject.EGG;
    public HatchHomeSnapshot Clone() => JsonUtility.FromJson<HatchHomeSnapshot>(JsonUtility.ToJson(this));

    public bool HasValidDurableIdentity()
    {
        if (!Enum.TryParse(phase, out HatchHomePhase parsedPhase) ||
            !Enum.TryParse(hatchCheckpoint, out HatchCheckpoint parsedCheckpoint) ||
            !Enum.TryParse(activeHomeView, out HomeSubject parsedSubject)) return false;

        var hasArt = selectedArtId is >= 1 and <= BigimongSpeciesCatalog.Count;
        return parsedPhase switch
        {
            HatchHomePhase.EGG_ACTIVE or HatchHomePhase.HATCH_READY =>
                selectedArtId == 0 && parsedCheckpoint == HatchCheckpoint.NONE &&
                parsedSubject is HomeSubject.EGG or HomeSubject.AVATAR,
            HatchHomePhase.HATCHING =>
                hasArt && parsedCheckpoint is HatchCheckpoint.STARTED or HatchCheckpoint.SHELL_BURST &&
                parsedSubject == HomeSubject.EGG,
            HatchHomePhase.REVEAL or HatchHomePhase.HOME =>
                hasArt && parsedCheckpoint == HatchCheckpoint.REVEALED &&
                parsedSubject is HomeSubject.DINOSAUR or HomeSubject.AVATAR,
            _ => false,
        };
    }
}
```

`Normalize()` must clamp progress/counters, parse enum strings with safe phase-specific defaults, trim empty event IDs, deduplicate them in insertion order, retain only the newest 256, deduplicate provider/day cursors by keeping the highest cumulative value, and force `selectedArtId = 0` in `EGG_ACTIVE`/`HATCH_READY`. It preserves `EGG`/`AVATAR` in those two phases, forces `EGG` during `HATCHING`, and preserves `DINOSAUR`/`AVATAR` in `REVEAL`/`HOME`, using the first valid subject in each pair as the fallback. Store reads must call `HasValidDurableIdentity()` on the raw deserialized value before normalization so malformed enum strings cannot silently become a fresh-looking identity.

```csharp
{
    if (current.Phase != HatchHomePhase.EGG_ACTIVE) return WrongPhase(current);
    var utcNow = clock.UtcNow;
    var effectiveTicks = Math.Max(utcNow.ToUniversalTime().Ticks, current.lastObservedUtcTicks);
    if (effectiveTicks < current.nextCareAtUtcTicks)

}
```
