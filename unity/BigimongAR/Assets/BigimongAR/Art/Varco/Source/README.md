# VARCO Unity bridge drop folder

Export or move the authenticated VARCO 3D Bridge results into this folder with these exact FBX names:

- `Avatar_Masculine.fbx` — existing `Stylized Male T-pose`
- `Avatar_Feminine.fbx` — `Chibi Female Model`
- `Bigimong_01_Baby.fbx` — `Cute Red Dragon`
- `Bigimong_01_Teen.fbx` — `Red Cartoon Dinosaur`
- `Bigimong_01_Adult.fbx` — `Red Fire Dragon`
- `Bigimong_Egg.fbx` — `Colorful Abstract Egg`

Do not add credentials, account asset IDs, private download URLs, or exported session data. Unity generates normalized runtime prefabs under `Assets/BigimongAR/Resources/GeneratedCharacters` and updates `ArCharacterCatalog` automatically.
